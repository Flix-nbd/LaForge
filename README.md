# LaForge — code + données

App LaForge (musculation + WOD), prête à être connectée à Claude Design / Claude Code via import GitHub.

## Contenu
- `app/laforge.html` — code de l'app (single-file HTML/JS, localStorage)
- `data/exercices_musculation.json` / `.csv` / `.xlsx` — 485 lignes exercice/groupe musculaire
- `data/index_par_equipement.json` — même données réindexées par équipement
- `data/wod_bank.json` — 217 WOD, organisés en 5 sections

Voir [`data/README.md`](data/README.md) pour le détail des fichiers de données.
